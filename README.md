# 艾澤拉斯攻略站

全新的獨立《魔獸世界》正式服繁體中文攻略入口。

## 範圍

- 30 個英文網站，依來源規則分成定期索引、單頁檢查與人工入口。
- Blizzard 台服官方網站負責正式譯名；巴哈姆特作為問題雷達。
- 30 個玩家導向攻略分類，不照搬任何單一英文網站的目錄。
- 免費本機翻譯：M2M100、OpenCC 與台服術語表。
- 可切換 Ollama 或其他未來翻譯器，不改動抓取與前端資料格式。
- macOS 本機排程與 GitHub Actions 備援。

## 更新

```bash
npm run crawl
npm run translate
```

完整頻率與回填階段見 `docs/SCHEDULE_PLAN.md`，來源比較見
`research/SOURCE_COVERAGE.md`。

## 權利與來源

網站只索引允許讀取的公開標題、短摘錄與連結，不重新散布付費內容、插件檔案、
來源圖片或禁止自動擷取的全文。各文章頁保留來源連結。

本專案為非官方玩家製作網站，與 Blizzard Entertainment 無關。
