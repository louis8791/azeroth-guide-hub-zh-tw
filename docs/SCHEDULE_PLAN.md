基準日期：2026-07-30  
時區：Asia/Taipei  
原則：免費、本機可執行、來源與翻譯器可替換、失敗不清空舊資料。

## 四階段回填

### 第 1 階段：現在版本與高頻問題（第 1–2 週）

- 官方公告、12.0.7／12.1 版本中心。
- 全職業與專精、團隊副本、傳奇鑰石、PvP。
- 滿等裝備、寶庫、探究、專業、插件與常見巴哈問題。
- 驗收：30 個分類都有入口；重要內容不超過 24 小時未檢查。

### 第 2 階段：工具與長尾玩法（第 3–4 週）

- 模擬、戰鬥紀錄、角色／公會排名。
- 坐騎、戰寵、成就、塑形、秘密與解謎。
- 任務卡關、聲望、活動、住宅與介面設定。
- 驗收：所有分類至少有兩個可交叉核對的來源，專門工具除外。

### 第 3 階段：舊版本與歷史資料（第 2–3 個月）

- 依資料片逐批回填舊副本、任務、收藏與世界觀。
- 每週限制新增量，避免免費模型一次處理過量。
- 驗收：每筆都有版本、來源、抓取時間與內容指紋。

### 第 4 階段：持續維護

- 新賽季前兩週提高官方與攻略索引頻率。
- 失效頁、重導向、robots 規則與頁面結構每週檢查。
- 低信心譯名進入術語表；已修正內容不重複翻譯。

## 失敗處理

1. 單一來源失敗：保留上次成功資料並記錄狀態。
2. robots 或條款不允許：自動降級為人工入口，不繞過限制。
3. 翻譯模型不可用：保留英文索引，等待下次本機執行，不用付費 API。
4. 網站更新失敗：公開站使用最後一次成功索引。
5. 模型替換：改 `config/pipeline.json` 或 `TRANSLATION_PROVIDER`，不需重寫抓取器。

## 免費運行方式

- 主要：macOS `launchd` 在本機執行，可使用 M2M100 或 Ollama。
- 備援：公開 GitHub 專案的 Actions 依相同排程執行。
- 網站：後端讀取公開資料索引；新資料不必為每次更新重做整站版面。
